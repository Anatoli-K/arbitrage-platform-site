# arbitrage-platform-site

Public informational website for **Arbitrage Platform**, a personal advertising
reporting application maintained by [Anatoli-K](https://github.com/Anatoli-K).

- Homepage: https://anatoli-k.github.io/arbitrage-platform-site/
- Privacy policy: https://anatoli-k.github.io/arbitrage-platform-site/privacy.html
- General support: https://github.com/Anatoli-K/arbitrage-platform-site/issues

## Files

- `index.html` — application description and purpose of Google access.
- `privacy.html` — Google data access, use, storage, sharing and revocation.
- `styles.css` and `favicon.svg` — local presentation assets.
- `.nojekyll` — publish the static files without Jekyll processing.

The site has no application sign-in, forms, JavaScript, analytics or external
assets. It contains no application credentials, spreadsheet identifiers,
private reports or server configuration. General support issues are public.

## Publication

GitHub Pages publishes the `main` branch from `/` (the repository root), with
HTTPS. No build tooling, dependencies or custom deployment workflow are needed.

Google Cloud's acceptance of these URLs is a separate configuration step.
Publishing this site does not verify domain ownership for Google's OAuth
review. Keep the policy aligned with the application's actual data use before
enabling additional spreadsheet update or report delivery features.
