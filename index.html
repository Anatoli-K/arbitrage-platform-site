Google data access

Selected files. A defined purpose.

Google authorization is used to access spreadsheets explicitly selected by the account owner. The current work concerns spreadsheet structure, formulas and reporting data needed to connect the reports.

The file permission supports reading and updating selected files. The owner can choose a reporting mode, request an update from current report files and receive the resulting dashboard image in their private Telegram chat.

Authorization takes place through Google's consent screen in the private setup workflow. This informational website does not collect Google credentials or provide a sign-in form.
